# 基本要求

《网络数据安全管理条例》自2025年1月1日起施行，要求网络数据处理者建立安全管理制度，并采取加密、备份、访问控制、安全认证等必要措施，防止数据被篡改、破坏、泄露或非法利用。

# Agent平台控制

科研协作平台应记录数据来源、处理目的、访问角色、模型调用与输出去向。敏感资料进入外部模型前需检查最小必要性和授权范围；日志与界面不得显示密钥、完整身份信息或其他不必要敏感字段。异常调用、越权访问和数据泄露应有终止与追踪机制。

# 证据边界

该条例支持安全控制与责任原则，不能单独判定某份科研材料是否属于重要数据，也不能代替个人信息、保密或行业规则的专项判断。
