# 基本要求

《中华人民共和国个人信息保护法》保护自然人的个人信息权益，规范个人信息处理活动。处理个人信息应具有明确、合理目的，并与处理目的直接相关，采取对个人权益影响最小的方式；收集范围应限于实现处理目的的最小范围。

# 科研与管理场景

科研管理材料可能包含研究人员身份、联系方式、履历、考核、健康或其他个人信息。把这些内容输入模型属于需要评估的数据处理环节。应先确认处理目的和依据，进行去标识化或匿名化，限制输入字段，控制访问者，并关注模型服务是否留存、再利用或跨境传输数据。

# 风险边界

匿名化与去标识化不是同一概念，简单删除姓名不一定消除重新识别风险。涉及敏感个人信息、未成年人信息、大规模处理或对个人权益有重大影响的活动，需要更严格的必要性论证和保护措施。本摘要不代替针对具体项目的合规评估。
