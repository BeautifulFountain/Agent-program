# 核心原则

《中华人民共和国数据安全法》规范数据处理活动，强调数据安全与开发利用并重。数据处理包括收集、存储、使用、加工、传输、提供和公开。国家建立数据分类分级保护制度，不同重要程度的数据应采取相应保护措施。

# 高校科研管理应用提示

科研项目申报、经费材料、实验记录、合作单位数据和未公开成果可能具有不同敏感程度。将材料发送给外部大模型之前，应完成数据识别、分类分级、最小必要处理和访问权限控制。对重要数据、敏感科研数据或涉及国家秘密的数据，不能仅依赖普通软件使用说明作出处理决定。

# 可执行控制

可建立输入数据清单、敏感字段脱敏、模型供应商评估、传输与留存记录、异常事件响应以及定期风险评估。该法不能直接推出所有科研数据均禁止使用云端模型，具体处理应结合数据类别、合同、行业规范和其他适用法律判断。
