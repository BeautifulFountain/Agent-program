# 适用范围

STROBE用于队列、病例对照和横断面观察性研究的透明报告。它是报告指南，不是研究质量评分工具，也不能替代研究设计与统计审查。

# 核心报告项目

标题或摘要应标明研究设计；引言说明背景和预设目标；方法报告研究环境、日期、参与者来源、纳排标准、变量定义、数据来源、偏倚控制、样本量和统计方法；结果报告各阶段人数、缺失数据、描述性统计和主要估计及不确定性；讨论解释局限与可推广性。

# 平台用途

对“大学生使用AI情况”等横断面调查，撰写 Agent 可据此检查是否报告了抽样方式、变量定义、缺失值和局限，但不能虚构尚未收集的数据或显著性检验结果。
