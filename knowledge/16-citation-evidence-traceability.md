# 证据链

每项关键事实应能追溯到具体资料标题、发布机构、日期、URL和命中片段。Agent生成的概括属于二次表述，不能把模型输出本身当作原始证据。

# 引用规则

引用应紧邻其支持的主张；法律政策结论优先链接正式原文；统计数字需保留口径、时间、总体与分母。未检索到资料只表示当前知识库未覆盖，不能推断学界没有研究。来源与结论不匹配时应标为待核验，而不是补造引用。

# 事实核验

事实核验 Agent 应用原任务重新检索知识库，对报告中的关键事实逐项比对原始片段，最多提出六项影响验收的问题。最终报告应区分已证实事实、合理推断、方案建议和待采集数据。
